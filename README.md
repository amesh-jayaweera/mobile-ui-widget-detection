# Rico Mobile-UI Detector (YOLO11n)

Train a YOLO11n object detector on the Rico mobile-UI screenshot dataset and
emit predictions as Pascal VOC XML files matching the Rico annotation schema.

## Dataset

The pipeline expects the Rico data at the repo root:

```text
Rico/
  Annotations/   # Pascal VOC XML, one per screenshot
  JPEGImages/    # corresponding .jpg files
```

## Classes

Trained on **14 classes** (rare classes with fewer than 50 instances were
dropped: `Multi_Tab`, `Bottom_Navigation`, `Spinner`, `Map`):

```text
Text, Icon, Image, TextButton, UpperTaskBar, PageIndicator, CheckedTextView,
EditText, BackgroundImage, Modal, Toolbar, Drawer, Switch, Card
```

## Setup

The system Python is `3.14`, but `torch`/`ultralytics` wheels typically lag a
few versions behind. If `pip install` below fails, create a Python 3.12 (or
3.11) virtualenv first:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

Then install dependencies:

```powershell
pip install -r requirements.txt
```

## 1. Prepare dataset

Convert VOC XML to YOLO format with a deterministic 80/20 train/val split:

```powershell
python scripts/prepare_dataset.py
```

This populates:

```text
data/
  images/{train,val}/*.jpg
  labels/{train,val}/*.txt
  data.yaml
```

Useful flags: `--rico Rico`, `--out data`, `--val-frac 0.2`, `--seed 42`.

## 2. Train

```powershell
python scripts/train.py --epochs 100
```

Common overrides:

```powershell
python scripts/train.py --epochs 150 --batch 8 --imgsz 640 --device 0
python scripts/train.py --batch -1                # auto-batch by VRAM
python scripts/train.py --device cpu              # CPU fallback
```

Best weights end up at `runs/rico_yolo11n/weights/best.pt`.

Training itself also writes evaluation plots into `runs/rico_yolo11n/`
(`results.png`, `P_curve.png`, `R_curve.png`, `F1_curve.png`, `PR_curve.png`,
`confusion_matrix.png`, `confusion_matrix_normalized.png`).

## 3. Evaluate (precision / recall / F1 / confusion matrix PNGs)

Re-run validation against `best.pt` to regenerate all metric plots without
retraining:

```powershell
python scripts/eval.py --weights runs/rico_yolo11n/weights/best.pt
```

This writes the following PNGs into `runs/rico_yolo11n_eval/`:

| File | Plot |
| --- | --- |
| `P_curve.png` | precision vs confidence |
| `R_curve.png` | recall vs confidence |
| `F1_curve.png` | F1 vs confidence |
| `PR_curve.png` | per-class precision-recall |
| `confusion_matrix.png` | raw counts |
| `confusion_matrix_normalized.png` | row-normalized |

It also prints the aggregate `precision / recall / mAP@0.5 / mAP@0.5:0.95`.
Pass `--copy-to reports/` to additionally copy the six PNGs into a clean
folder you can hand to others.

## 4. Predict (XML output)

Run inference on a single image or a directory of images. Each input image
produces a `.xml` file in `--out` matching the Rico VOC schema:

```powershell
python scripts/predict.py `
  --weights runs/rico_yolo11n/weights/best.pt `
  --source path/to/screenshot.jpg `
  --out predictions/

python scripts/predict.py `
  --weights runs/rico_yolo11n/weights/best.pt `
  --source path/to/folder_of_screenshots `
  --out predictions/ --conf 0.25 --iou 0.5 --save-vis
```

Output XML structure:

```xml
<annotation>
    <folder>JPEGImages</folder>
    <filename>screenshot.jpg</filename>
    <size>
        <width>1080</width>
        <height>1794</height>
        <depth>3</depth>
    </size>
    <object>
        <name>Icon</name>
        <difficult>0</difficult>
        <bndbox>
            <xmin>491</xmin>
            <ymin>49</ymin>
            <xmax>526</xmax>
            <ymax>89</ymax>
        </bndbox>
    </object>
</annotation>
```

Pass `--save-vis` to additionally save annotated preview images under
`<out>/vis/`.
